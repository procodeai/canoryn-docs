# What Canoryn does

A running list of what the app can do today, grouped by what you are trying to get done. Each line links to the page that explains it. When something ships, it is added here.

## Work with an agent

- **Chat with an agent about a project.** Attach folders to a session; the agent reads, searches, edits and runs commands in them, showing each step and asking before anything that needs consent. → [Chat workbench](/guide/chat-workbench)
- **Agent core (preview).** A newer loop that checks every edit it makes, shares one language server with the editor, and has you review its plan first. → [Agent core](/guide/agent-core)
- **Your own models.** OpenAI, Anthropic, Gemini, a ChatGPT subscription, or local models through Ollama. → [Local processing](/guide/local-processing)
- **From other tools.** Drive Canoryn from the terminal or another agent. → [CLI & MCP](/guide/cli-and-mcp)

## Write and review code

- **A real code editor.** 25 languages, language servers, folding, multiple carets, find and replace, snippets, rename. → [Code editor](/guide/code-editor), [Language servers](/guide/language-servers)
- **Review what changed.** Every changed file in one list, the lines Git folded away a drag away, comments that stay put. → [Review workbench](/guide/review-workbench), [Reviewing a diff](/guide/reviewing-a-diff)
- **Git without leaving the editor.** See changes in the gutter, stage hunks and lines, commit one change with a generated message, and undo a commit. → [Git & commits](/guide/git-and-commits)
- **Comments on code.** Threads on lines, shared with the agent. → [Annotations](/guide/annotations)

## Write documents

- **Markdown that reads like a page.** Preview, Edit (write as it reads) and Source; properties, callouts, diagrams, math, tables. → [Documents](/guide/documents)
- **Blocks and the `/` menu.** Move, turn into, duplicate; insert anything by typing `/`. → [Documents](/guide/documents#blocks)
- **Comments on documents**, shared with the agent, which edits and replies. → [Documents](/guide/documents#comments)
- **AI you approve.** Improve, summarise, continue, translate, or write from a template — every change a proposal. → [AI in documents](/guide/document-ai)
- **Share it.** Export a web page, PDF or bundle; keep the discussion in the repository; publish to canoryn.app. → [Sharing & publishing](/guide/sharing-documents)

## Build workflows on a canvas

- **Build with chat.** Describe a workflow and watch it appear; edit one step without rebuilding. → [Build with chat](/guide/build-with-chat)
- **Live browsers and terminals** on one canvas, left running while you work elsewhere. → [Browser nodes](/guide/browser-nodes), [Research boards](/guide/research-boards)
- **Saved workflows** you reopen from Finder and run again. → [Workflows](/guide/workflows), [Architect](/architect/overview)

## Around the app

- **Appearance** — syntax themes, typography, translucency. → [Appearance](/guide/appearance)
- **Memory** — what the assistant keeps about you and your projects. → [Memory](/guide/memory)
- **Permissions and privacy** — what runs locally and what asks first. → [Permissions](/guide/permissions)
- **Crash reports you choose to send**, and update checks while you work. → [Troubleshooting](/guide/troubleshooting)
